# Legacy Prototype

This directory is reserved for the original smart-glasses prototype scripts.

The project originally consisted of several larger scripts covering:

- Camera capture
- Microphone recording
- Whisper speech recognition
- Google Drive upload/download
- OCR with Tesseract
- Text-to-speech with gTTS
- Pygame audio playback
- Ultrasonic obstacle detection

The current `src/` directory reorganizes those responsibilities into smaller modules.

If the original source files are recovered, they can be placed here without mixing historical prototype code with the cleaned implementation.

The legacy code should be treated as historical reference rather than production-ready software.
